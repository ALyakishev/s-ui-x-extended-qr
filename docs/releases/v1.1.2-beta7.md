# S-UI-X Extended v1.1.2-beta7

## Ядро

Панель переходит на sing-box-extended `v1.14.3-extended-2.7.8`. Предыдущий beta6 работал на `v1.14.1-extended-2.7.6`.

Пришлось перестроить загрузку ядра: компоненты теперь запускаются в том порядке, который ожидает новая версия sing-box. NTP-сервис, менеджер ссылок и клиент HTTP останавливаются вместе с ядром, а не после него.

В формах TrustTunnel и MASQUE появились новые поля из схемы ядра. В TrustTunnel это `disable_path_mtu_discovery`, в MASQUE `handshake_timeout` и `use_l4_proxy`.

## Исправления

Валидатор внешних URL отвергал домены в punycode. Адреса вроде `http://xn--e1afmkfd.xn--p1ai/` не проходили проверку, хотя настраивать их разрешено. Теперь TLD принимается, если в нём есть хотя бы одна буква.

Маскировщик логов вырезал логин и пароль только из URL со схемой. Строка `dial user:pass@host:443` попадала в журнал как есть. Теперь учётные данные вырезаются и без схемы.

## Установка и обновление

Перед обновлением сделайте резервную копию базы.

```sh
curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.1.2-beta7/install.sh \
  | sudo bash -s -- v1.1.2-beta7
```

Для Windows скачайте ZIP своей архитектуры и запустите `install-windows.bat` от имени администратора. Docker-образ: `ghcr.io/deposist/s-ui-x-extended:v1.1.2-beta7`.

Стабильная версия остаётся `v1.1.1`. Настройки, клиенты и outbound сохраняются при обновлении.

## Откат

Держите под рукой копию базы, сделанную до обновления. Откат на beta6 и старше безопасен: формат конфигурации не менялся.

## English

The panel moves to sing-box-extended `v1.14.3-extended-2.7.8`, up from `v1.14.1-extended-2.7.6` in beta6.

Core startup needed rebuilding to follow the order the new sing-box expects. NTP, the reference manager and the HTTP client now stop with the core instead of after it.

TrustTunnel and MASQUE forms gain fields from the core schema: `disable_path_mtu_discovery` for TrustTunnel, `handshake_timeout` and `use_l4_proxy` for MASQUE.

Two fixes. The outbound URL validator rejected punycode domains such as `http://xn--e1afmkfd.xn--p1ai/`; it now accepts a TLD that contains at least one letter. The log redactor stripped credentials only from URLs with a scheme, so `dial user:pass@host:443` reached the log intact; schemeless credentials are masked now.

Back up the database before upgrading. The install command above works for Linux and macOS; on Windows use the ZIP for your architecture and run `install-windows.bat` as Administrator. Docker image: `ghcr.io/deposist/s-ui-x-extended:v1.1.2-beta7`. Stable remains `v1.1.1`. Settings, clients and outbounds are preserved. Rollback to beta6 needs only the pre-upgrade database copy, because the configuration format is unchanged.
