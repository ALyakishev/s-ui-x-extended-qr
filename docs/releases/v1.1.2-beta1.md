# v1.1.2-beta1

Released: 2026-10-14. Prerelease; stable remains `v1.1.1`.

## MTProxy logs

MTProxy authentication rejections with `incorrect client random` now use the debug level. Stream start/finish messages and relay shutdown with `io: read/write on closed pipe` also use debug. They no longer fill the normal info/error log; enable debug logging to inspect them.

Other handshake and transport failures retain their existing severity. Authentication and connection handling are unchanged, as are routing, client secrets and the database schema.

## Security

Builds use Go `1.26.9` and `golang.org/x/net v0.60.0`, fixing known vulnerabilities in HTTP/HTTP2, TLS, multipart parsing and templates.

## Install or upgrade

```sh
curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.1.2-beta1/install.sh \
  | sudo bash -s -- v1.1.2-beta1
```

The installer preserves the panel database and configuration. The service restart briefly interrupts active connections.

```sh
/usr/local/s-ui/sui -v
systemctl is-active s-ui
```

Windows: download the ZIP for your architecture from the [release page](https://github.com/deposist/s-ui-x-extended/releases/tag/v1.1.2-beta1), extract it and run `install-windows.bat` as Administrator.

Docker image: `ghcr.io/deposist/s-ui-x:v1.1.2-beta1`.

## По-русски

В этой beta сообщения `incorrect client random`, начало/завершение потоков MTProxy и закрытие relay с `io: read/write on closed pipe` переведены на уровень debug. Для диагностики отклонённых соединений включите debug. Остальные ошибки сохраняют прежний уровень.

Обновлены Go до `1.26.9` и `golang.org/x/net` до `v0.60.0` с исправлениями известных уязвимостей HTTP/HTTP2, TLS, multipart-парсинга и шаблонов. Ключи MTProxy, проверка подлинности, маршрутизация и схема базы данных не меняются. Установщик сохраняет базу и настройки; перезапуск службы кратковременно прерывает соединения. Команда обновления и ссылки на сборки приведены выше.
