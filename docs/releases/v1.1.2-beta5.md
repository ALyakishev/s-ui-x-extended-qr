# v1.1.2-beta5

Released: 2026-10-19. Prerelease; stable remains `v1.1.1`.

## Changes

This beta fixes Windows ARM64 release packaging and corrects Docker installation commands. It includes the subscription features from the earlier 1.1.2 betas; subscription behavior is unchanged from beta4.

## Configure a Subscription outbound

1. Open Outbounds and add an outbound of type Subscription.
2. Enter the subscription URL and choose the user agent required by your provider.
3. If required, enter a provider-authorized HWID. Assign automatically generates an editable UUID; it does not copy an identifier from your device.
4. Optionally enter Device OS, Device model and OS version. For example:

   ```http
   X-Device-OS: Android
   X-Device-Model: Samsung Galaxy S24
   X-Ver-OS: 14
   ```

5. Click Load servers, select the primary server and optionally a backup, then save the outbound.
6. Use the saved outbound tag in the route or group that should send traffic through it.

Device details and HWID are saved with the outbound and reused for downloads and automatic subscription refreshes after a restart. Empty fields omit their headers. The panel does not infer device details from your browser or the server. After changing these fields, load the server list and select the servers again before saving.

Redirects to a different host, port or HTTP/HTTPS scheme do not receive device headers or HWID. If your provider requires these headers, use its final subscription URL.

Xray JSON and proprietary encrypted subscriptions are not supported.

## Install or upgrade

Back up the panel database before upgrading.

```sh
curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.1.2-beta5/install.sh \
  | sudo bash -s -- v1.1.2-beta5
```

Windows: download the ZIP for your architecture from the [release page](https://github.com/deposist/s-ui-x-extended/releases/tag/v1.1.2-beta5), extract it and run `install-windows.bat` as Administrator.

Docker image: `ghcr.io/deposist/s-ui-x-extended:v1.1.2-beta5`.

Existing installations keep their settings, users, inbounds, outbounds, clients, TLS configuration, services and tokens.

## Rollback

Beta3 does not send device detail headers. If your provider requires them, subscription downloads can fail after rolling back. Versions before beta3 also lack HWID support.

Versions older than beta2 do not recognize Subscription outbounds. Before rolling back to them, remove these outbounds and update the rules and groups that reference them, or restore the database backup from before the upgrade.

## По-русски

В beta5 исправлена упаковка Windows ARM64 и Docker-команды установки. Работа подписок по сравнению с beta4 не изменилась. Стабильная версия остаётся `v1.1.1`.

В разделе Outbounds создайте outbound «Подписка», укажите URL и нужный провайдеру user agent. При необходимости задайте разрешённый провайдером HWID вручную или нажмите «Назначить автоматически», чтобы создать редактируемый UUID. Это действие не считывает идентификатор вашего устройства.

Необязательные поля «ОС устройства», «Модель устройства» и «Версия ОС» передаются как `X-Device-OS`, `X-Device-Model` и `X-Ver-OS`. Например: `Android`, `Samsung Galaxy S24`, `14`. Нажмите «Загрузить серверы», выберите основной и при необходимости резервный сервер, затем сохраните outbound. Используйте его тег в нужных правилах или группах.

HWID и сведения об устройстве сохраняются и повторно используются при загрузке и автообновлении подписки после перезапуска. Пустые поля не отправляются; панель не определяет их по браузеру или серверу. После изменения заново загрузите список и выберите серверы. При редиректе на другой хост, порт или протокол HTTP/HTTPS эти заголовки не передаются. Если провайдер требует их, укажите конечный URL подписки. Xray JSON и проприетарные зашифрованные подписки не поддерживаются.

Команда обновления приведена выше. Для Windows скачайте ZIP своей архитектуры и запустите `install-windows.bat` от имени администратора. Docker: `ghcr.io/deposist/s-ui-x-extended:v1.1.2-beta5`. Перед обновлением сделайте резервную копию базы; существующие настройки сохраняются.

Beta3 не передаёт сведения об устройстве; если они обязательны у провайдера, после отката загрузка подписки может перестать работать. Версии до beta3 также не поддерживают HWID. Версии до beta2 не распознают outbound «Подписка»: перед откатом удалите эти outbound и измените ссылающиеся на них правила и группы либо восстановите базу из копии до обновления.
