# v1.1.2-beta3

Released: 2026-10-19. Prerelease; stable remains `v1.1.1`.

## Set a subscription HWID

Subscription outbounds can now send an optional `X-HWID` header. Use the identifier allowed by your provider. Generating a UUID does not register a device with the provider or change its device limits.

1. Open Outbounds and create or edit a Subscription outbound.
2. Enter HWID manually, or click Assign automatically to generate a UUID. The field stays editable. Leave it empty if the provider does not require `X-HWID`.
3. Click Load servers and select the primary and, optionally, a different backup from the same subscription.
4. Save the outbound. Saving restarts the core and briefly interrupts active connections.

The panel saves HWID with the outbound. Server-list downloads and scheduled subscription refreshes reuse it, including after a panel restart. Clearing the field stops the panel from sending the header. After changing or clearing HWID, reload the list and select the servers again before saving. Your provider may count a new identifier as another device.

The header is stripped on redirects to a different host, port or HTTP/HTTPS scheme. If a subscription service redirects to another origin that also requires HWID, use the final subscription URL supplied by the provider.

Primary selection, failover and supported subscription formats are unchanged from [beta2](v1.1.2-beta2.md). Supported formats are share links, base64 lists, sing-box JSON and Clash/Mihomo YAML. Xray JSON and proprietary encrypted subscriptions are not supported.

## Install or upgrade

Back up the panel database before installing this beta.

```sh
curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.1.2-beta3/install.sh \
  | sudo bash -s -- v1.1.2-beta3
```

The installer preserves the database and configuration. Restarting the service briefly interrupts active connections.

```sh
/usr/local/s-ui/sui -v
systemctl is-active s-ui
```

Windows: download the ZIP for your architecture from the [release page](https://github.com/deposist/s-ui-x-extended/releases/tag/v1.1.2-beta3), extract it and run `install-windows.bat` as Administrator.

Docker image: `ghcr.io/deposist/s-ui-x:v1.1.2-beta3`.

## Rollback

Beta2 does not send HWID headers. If your provider requires HWID, subscription downloads will fail after rolling back to beta2.

Versions before beta2 do not recognize Subscription outbounds. Remove those outbounds and update the rules and groups that reference them before rolling back, or restore the database backup made before the upgrade.

## По-русски

### HWID подписки

В outbound «Подписка» добавлено необязательное поле HWID. Используйте идентификатор, разрешённый провайдером. Кнопка «Назначить автоматически» создаёт редактируемый UUID; она не регистрирует устройство у провайдера и не меняет его лимиты.

Откройте или создайте outbound «Подписка», введите HWID либо назначьте его кнопкой. Нажмите «Загрузить серверы», выберите основной и при необходимости резервный сервер из той же подписки, затем сохраните. Сохранение перезапускает ядро и кратковременно прерывает соединения.

Панель сохраняет идентификатор вместе с outbound и передаёт его в заголовке `X-HWID` при загрузке списка серверов и автообновлении подписки. Перезапуск панели его не меняет. Пустое поле отключает заголовок. После смены или очистки HWID нужно заново загрузить список и выбрать серверы перед сохранением. Провайдер может учитывать новый HWID как отдельное устройство.

При редиректе на другой хост или порт, а также при смене HTTP/HTTPS идентификатор не передаётся. Если конечный адрес тоже требует HWID, используйте конечный URL подписки, выданный провайдером.

Выбор основного сервера, failover и форматы подписок не изменились по сравнению с [beta2](v1.1.2-beta2.md). Поддерживаются ссылки, списки base64, sing-box JSON и Clash/Mihomo YAML. Xray JSON и проприетарные зашифрованные подписки не поддерживаются.

### Обновление и откат

Перед установкой сделайте резервную копию базы. Команда обновления, проверка версии и ссылки на сборки приведены выше.

Beta2 не передаёт HWID. Если провайдер требует этот заголовок, загрузка подписки после отката на beta2 перестанет работать. Версии до beta2 не распознают outbound «Подписка»: перед откатом удалите их и измените ссылающиеся на них правила и группы либо восстановите базу из копии до обновления.
