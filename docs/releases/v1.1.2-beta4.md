# v1.1.2-beta4

Released: 2026-10-19. Prerelease; stable remains `v1.1.1`.

## Set subscription device details

Subscription outbounds now let you set Device OS, Device model and OS version. These optional values describe the device to your subscription provider. They are separate from HWID and User-Agent.

1. Open Outbounds and create or edit a Subscription outbound.
2. Enter the values your provider expects. For an Android phone, an example is Device OS `Android`, Device model `Samsung Galaxy S24` and OS version `14`.
3. Click Load servers and select the primary and, optionally, a different backup from the same subscription.
4. Save the outbound. Saving restarts the core and briefly interrupts active connections.

The panel sends the example values as:

```http
X-Device-OS: Android
X-Device-Model: Samsung Galaxy S24
X-Ver-OS: 14
```

Each field is editable and can be left empty. Empty fields omit their corresponding headers. Values are not inferred from the browser or the machine running the panel.

Saved values are reused when loading servers and automatically refreshing the subscription, including after a panel restart. After changing or clearing device details, reload the list and select the servers again before saving.

Redirects to another host, port or HTTP/HTTPS scheme strip these headers and HWID. If the destination also needs them, use the final subscription URL supplied by your provider.

Primary selection and failover are unchanged; see the [subscription guide](v1.1.2-beta2.md). [HWID setup](v1.1.2-beta3.md) is also unchanged. Supported formats remain share links, base64 lists, sing-box JSON and Clash/Mihomo YAML. Xray JSON and proprietary encrypted subscriptions are not supported.

## Install or upgrade

Back up the panel database before installing this beta.

```sh
curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.1.2-beta4/install.sh \
  | sudo bash -s -- v1.1.2-beta4
```

The installer preserves the database and configuration. Restarting the service briefly interrupts active connections.

```sh
/usr/local/s-ui/sui -v
systemctl is-active s-ui
```

Windows: download the ZIP for your architecture from the [release page](https://github.com/deposist/s-ui-x-extended/releases/tag/v1.1.2-beta4), extract it and run `install-windows.bat` as Administrator.

Docker image: `ghcr.io/deposist/s-ui-x:v1.1.2-beta4`.

## Rollback

Beta3 does not send device detail headers. If your provider requires them, subscription downloads can fail after rolling back. Versions before beta3 also lack HWID support.

Versions before beta2 do not recognize Subscription outbounds. Before rolling back to those versions, remove Subscription outbounds and update the rules and groups that reference them, or restore the database backup made before the upgrade.

## По-русски

### Сведения об устройстве

В outbound «Подписка» добавлены поля «ОС устройства», «Модель устройства» и «Версия ОС». Это необязательные сведения для провайдера, отдельные от HWID и User-Agent. Например, значения `Android`, `Samsung Galaxy S24` и `14` передаются в заголовках `X-Device-OS`, `X-Device-Model` и `X-Ver-OS`.

Откройте или создайте outbound «Подписка», заполните нужные поля, загрузите список серверов и выберите основной и при необходимости резервный. Затем сохраните outbound. Сохранение перезапускает ядро и кратковременно прерывает соединения.

Значения можно редактировать; пустые поля не отправляются. Панель не определяет их по браузеру или ОС сервера. Сохранённые сведения используются при загрузке списка и автообновлении подписки, в том числе после перезапуска панели. После изменения или очистки полей заново загрузите список и выберите серверы перед сохранением.

При редиректе на другой хост, порт или протокол HTTP/HTTPS сведения об устройстве и HWID не передаются. Если конечный адрес тоже требует их, используйте конечный URL подписки, выданный провайдером.

Выбор серверов, failover, HWID и форматы подписок не изменились. Xray JSON и проприетарные зашифрованные подписки не поддерживаются.

### Обновление и откат

Перед установкой сделайте резервную копию базы. Команда обновления, проверка версии и ссылки на сборки приведены выше.

Beta3 не передаёт сведения об устройстве. Если провайдер требует эти заголовки, после отката загрузка подписки может перестать работать. Версии до beta3 также не поддерживают HWID. Версии до beta2 не распознают outbound «Подписка»: перед откатом на них удалите эти outbound и измените ссылающиеся на них правила и группы либо восстановите базу из копии до обновления.
