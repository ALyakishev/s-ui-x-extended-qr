# v1.1.2-beta2

Released: 2026-10-19. Prerelease; stable remains `v1.1.1`.

## Subscription outbounds

A Subscription outbound uses a specific server from a subscription. You can also select a backup from the same subscription. Use the outbound's tag in routing rules and selectors as you would for another outbound.

1. Open Outbounds, add an outbound and choose Subscription.
2. Enter its tag and subscription URL. Set User-Agent if your provider requires one, then click Load servers.
3. Select the primary server and, optionally, a different backup.
4. With a backup selected, set the HTTPS health check URL, check interval and number of successful checks before returning to the primary. Defaults are `https://www.gstatic.com/generate_204`, `30s` and `2` successful checks; the minimum interval is `5s`.
5. Set the subscription refresh interval (`24h` by default, minimum `1m`) and save. Saving restarts the core and briefly interrupts active connections.

The panel probes through the selected servers. If the primary fails, it switches to the backup. Once the primary passes the configured consecutive checks, traffic returns to it. If both fail, the current selection remains in place. There is no automatic direct fallback.

Refresh matches servers by exact unique name, regardless of their order in the subscription. A failed download, invalid configuration, duplicate selected name or missing selected server keeps the last saved configuration. Changed settings for the selected servers trigger a core restart. Changing the subscription URL or User-Agent clears the form's selections; load the list again before saving.

## Supported subscriptions and limits

HTTP(S) subscriptions used by Happ and Hiddify can contain share links, base64 lists, sing-box JSON or Clash/Mihomo YAML. `happ://add/` and `hiddify://import/` wrappers around an HTTP(S) URL are accepted. Proprietary encrypted links are not supported.

Servers must have unique names and use protocols supported by the bundled core. Subscription nodes that depend on local files, outbound detours or other local configuration cannot be selected. A subscription supplies server settings, not routing rules or DNS settings.

## Install or upgrade

Back up the panel database before installing this beta.

```sh
curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.1.2-beta2/install.sh \
  | sudo bash -s -- v1.1.2-beta2
```

The installer preserves the database and configuration. Restarting the service briefly interrupts active connections.

```sh
/usr/local/s-ui/sui -v
systemctl is-active s-ui
```

Windows: download the ZIP for your architecture from the [release page](https://github.com/deposist/s-ui-x-extended/releases/tag/v1.1.2-beta2), extract it and run `install-windows.bat` as Administrator.

Docker image: `ghcr.io/deposist/s-ui-x:v1.1.2-beta2`.

Older versions do not understand Subscription outbounds. Before rolling back, remove those outbounds and update any rules or groups that reference them, or restore the database backup made before this upgrade.

## По-русски

В Outbounds появился тип «Подписка»: можно выбрать конкретный основной сервер и резервный из той же подписки. Для маршрутизации используйте тег созданного outbound.

В форме укажите URL и при необходимости User-Agent, нажмите «Загрузить серверы» и выберите серверы. Для резервирования доступны HTTPS-адрес проверки, интервал (по умолчанию `30s`, минимум `5s`) и число успешных проверок до возврата на основной (по умолчанию `2`). Подписка обновляется раз в `24h`; можно задать интервал от `1m`. Сохранение перезапускает ядро и кратковременно прерывает соединения.

При отказе основного трафик переключается на резервный. После восстановления и нужного числа последовательных успешных проверок снова используется основной. При отказе обоих остаётся текущий выбор; автоматического выхода через direct нет.

Выбор закреплён по точному уникальному имени и не зависит от порядка серверов. Ошибка загрузки, некорректное обновление, дублирование имени или исчезновение выбранного сервера сохраняют последнюю конфигурацию. Изменения настроек выбранных серверов применяются с перезапуском ядра. После смены URL или User-Agent нужно заново загрузить список и выбрать серверы.

Поддерживаются HTTP(S)-подписки Happ и Hiddify со ссылками, списками base64, sing-box JSON и Clash/Mihomo YAML, в том числе обёртки `happ://add/` и `hiddify://import/`. Проприетарные зашифрованные ссылки, зависимости от локальных файлов и outbound detour не поддерживаются. Правила и DNS из подписки не импортируются.

Команда обновления и ссылки на сборки приведены выше. Перед установкой beta сделайте резервную копию базы. Для отката удалите outbound типа «Подписка» и измените ссылающиеся на них правила и группы либо восстановите базу из копии до обновления: предыдущие версии этот тип не распознают.
