# S-UI-X Extended v1.1.2-beta6

## Core update

The panel now uses sing-box-extended `v1.14.1-extended-2.7.6`, based on upstream `v1.14.1-extended-2.7.2`.

AmneziaWG 3.1 options, the random-trailers handshake fix and live WireGuard peer management are preserved. Clash API mode handling and core log output use the new core interfaces.

Subscription outbounds work as in beta5. Primary-server selection, optional failover, HWID and device details remain available. See the [subscription guide](v1.1.2-beta5.md) for supported formats, request headers and setup steps.

## Install or upgrade

Back up the database before upgrading.

```sh
curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.1.2-beta6/install.sh \
  | sudo bash -s -- v1.1.2-beta6
```

For Windows, download the ZIP for your architecture and run `install-windows.bat` as Administrator. For Docker, use `ghcr.io/deposist/s-ui-x-extended:v1.1.2-beta6`.

Stable remains `v1.1.1`. Existing settings and saved outbounds are retained.

## Rollback

Keep the database backup from before the upgrade. Versions older than `v1.1.2-beta2` do not recognize Subscription outbounds: remove those outbounds and update their references before rolling back, or restore the earlier database backup. Versions before beta3 do not support HWID; beta3 does not send device-detail headers.

## По-русски

Панель использует sing-box-extended `v1.14.1-extended-2.7.6` на основе upstream `v1.14.1-extended-2.7.2`. Сохранены параметры AmneziaWG 3.1, исправление handshake со случайными трейлерами и управление WireGuard-пирами без перезапуска ядра. Режимы Clash API и вывод журналов адаптированы к новым интерфейсам.

Перед обновлением сделайте резервную копию базы. Команда установки приведена выше. Для Windows скачайте ZIP своей архитектуры и запустите `install-windows.bat` от имени администратора. Docker-образ: `ghcr.io/deposist/s-ui-x-extended:v1.1.2-beta6`. Настройки и сохранённые outbound сохраняются; стабильная версия остаётся `v1.1.1`.

Работа подписок соответствует beta5. Настройка основного сервера, failover, HWID и сведений об устройстве описана в [руководстве по подпискам](v1.1.2-beta5.md). Перед откатом на версии до beta2 удалите outbound «Подписка» и измените ссылающиеся на них правила и группы либо восстановите базу из копии до обновления. Версии до beta3 не поддерживают HWID; beta3 не передаёт сведения об устройстве.
